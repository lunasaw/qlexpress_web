# QLExpress + LiteFlow 可视化编排前端技术方案 V2.0

> **版本**: 2.0
> **更新日期**: 2024-12-18
> **变更说明**: 基于 liteflow-editor-client 深度分析和 LiteFlow 官方文档验证，优化数据模型、节点类型、API 对接等核心设计

---

## 一、项目概述

### 1.1 项目背景

基于后端 QLExpress + LiteFlow 组件化编排方案，开发配套的前端可视化编排系统。系统包含三大核心功能：

| 功能模块 | 描述 | 核心能力 |
|---------|------|---------|
| **组件设计器** | 创建和管理 QLExpress 脚本组件 | CRUD、脚本编辑、验证测试 |
| **流程编排器** | 可视化拖拽构建 LiteFlow 流程 | 画布交互、EL 生成、流程部署 |
| **脚本执行器** | 执行和调试 QL 脚本/流程 | 参数配置、结果展示、追踪分析 |

### 1.2 技术栈选型

| 技术 | 版本 | 用途 | 选型依据 |
|------|------|------|---------|
| React | 18.x | UI 框架 | 生态成熟、社区活跃 |
| TypeScript | 5.x | 类型安全 | 大型项目必备 |

| @antv/x6-react-shape | 2.x | React 节点渲染 | X6 官方推荐 |
| @antv/x6-plugin-dnd | 2.x | 拖拽交互 | X6 官方插件 |

| Ant Design | 5.x | UI 组件库 | 企业级设计规范 |

| Vite | 5.x | 构建工具 | 极速开发体验 |
| dagre | 1.x | 自动布局 | liteflow-editor-client 验证可行 |

**项目位置**: `qlexpress_web/frontend/`

// types/flow.ts

/**
 * 属性配置 - 对应后端 CmpProperty.Properties

export interface CmpProperties {
  id?: string;            // .id("xxx") - 表达式标识
  tag?: string;           // .tag("xxx") - 节点标签
  data?: string;          // .data("xxx") - 节点数据

  branch?: string;

  // WHEN 配置

  // 循环配置
  loopCount?: number;         // FOR 循环次数
  breakCondition?: CmpProperty;  // BREAK 条件
}

/**
 * 可视化组件树节点 - 对应后端 CmpProperty
 * 用于前端画布与后端 EL 表达式双向转换
 *
 * 设计要点：
 * 1. 树形结构表示编排关系
 * 2. type 区分编排类型和节点类型
 * 3. componentRef 引用 QLComponent.componentId
 */
export interface CmpProperty {
  // ===== 节点标识 =====
  id?: string;            // 节点 ID (自动生成或组件ID)

  /**
   * 节点类型
   * - 编排类型: THEN, WHEN, IF, SWITCH, FOR, WHILE, CATCH, AND, OR, NOT
   * - 节点类型: CommonNode, BooleanNode, SwitchNode, COMPONENT
   */
  type: string;

  // ===== 组件引用 (叶子节点) =====
  componentRef?: string;  // 引用 QLComponent.componentId

  // ===== 属性配置 =====
  properties?: CmpProperties;

  // ===== 条件节点 (IF/SWITCH/FOR/WHILE) =====
  condition?: CmpProperty;

  // ===== 子节点 (树结构) =====
  children?: CmpProperty[];
}

/**
 * 流程设计 - 对应后端 FlowDesign
 */
export interface FlowDesign {
  flowId: string;
  flowName: string;
  description?: string;
  category?: string;
  root: CmpProperty;      // 编排定义根节点
  version?: string;
  tags?: string[];
  enabled?: boolean;
  metadata?: Record<string, any>;
}

### 2.4 ELNode 模型 (前端内部使用)

> 基于 liteflow-editor-client 设计，用于前端画布操作和 X6 渲染

```typescript
// model/ELNode.ts

import { NodeTypeEnum, ConditionTypeEnum } from '../types/enums';
import type { CmpProperties, CmpProperty } from '../types/flow';
import type { QLComponent } from '../types/component';

/**
 * ELNode - 前端编排节点模型
 *
 * 设计模式: 树形结构 + 双向链接
 * 核心职责:
 * 1. 管理节点树形结构 (parent/children)
 * 2. 转换为 X6 图形数据 (toCells)
 * 3. 转换为 EL 表达式 (toEL)
 * 4. 转换为后端 CmpProperty JSON (toJSON)
 */
export abstract class ELNode {
  // ===== 节点标识 =====
  id: string;
  type: ConditionTypeEnum | NodeTypeEnum;

  // ===== 树形结构 =====
  parent?: ELNode;
  children: ELNode[] = [];

  // ===== 条件节点 (IF/SWITCH/FOR/WHILE 使用) =====
  condition?: ELNode;

  // ===== 属性配置 =====
  properties?: CmpProperties;

  // ===== 组件引用 (叶子节点) =====
  componentRef?: string;
  componentData?: QLComponent;

  constructor(parent?: ELNode, type?: ConditionTypeEnum | NodeTypeEnum) {
    this.id = this.generateId();
    this.type = type!;
    this.parent = parent;
  }

  private generateId(): string {
    return `node_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
  }

  // ===== 子节点操作 =====
  appendChild(child: ELNode, index?: number): boolean {
    child.parent = this;
    if (index !== undefined) {
      this.children.splice(index, 0, child);
    } else {
      this.children.push(child);
    }
    return true;
  }

  prependChild(child: ELNode): boolean {
    child.parent = this;
    this.children.unshift(child);
    return true;
  }

  removeChild(child: ELNode): boolean {
    const index = this.children.indexOf(child);
    if (index > -1) {
      this.children.splice(index, 1);
      child.parent = undefined;
      return true;
    }
    return false;
  }

  replace(newNode: ELNode): boolean {
    if (!this.parent) return false;
    const index = this.parent.children.indexOf(this);
    if (index > -1) {
      this.parent.children[index] = newNode;
      newNode.parent = this.parent;
      this.parent = undefined;
      return true;
    }
    return false;
  }

  // ===== 抽象方法 =====
  abstract toCells(): any[];           // 转换为 X6 图形数据
  abstract toEL(prefix?: string): string;  // 转换为 EL 表达式

  // ===== JSON 转换 (对接后端 CmpProperty) =====
  toJSON(): CmpProperty {
    const json: CmpProperty = {
      type: this.type,
    };

    if (this.componentRef) {
      json.componentRef = this.componentRef;
      json.id = this.componentRef;
    }

    if (this.properties) {
      json.properties = { ...this.properties };
    }

    if (this.condition) {
      json.condition = this.condition.toJSON();
    }

    if (this.children.length > 0) {
      json.children = this.children.map(child => child.toJSON());
    }

    return json;
  }

  // ===== 属性修饰符生成 =====
  protected propertiesToEL(): string {
    if (!this.properties) return '';

    const parts: string[] = [];
    const props = this.properties;

    if (props.id) parts.push(`.id("${props.id}")`);
    if (props.tag) parts.push(`.tag("${props.tag}")`);
    if (props.data) parts.push(`.data("${props.data}")`);
    if (props.maxWaitSeconds) parts.push(`.maxWaitSeconds(${props.maxWaitSeconds})`);
    if (props.ignoreError) parts.push(`.ignoreError(true)`);
    if (props.must) parts.push(`.must()`);

    return parts.join('');
  }
}
```

### 3.2 EL 操作符与 LiteFlow 对照表

| 前端节点类型 | LiteFlow EL | 语法示例 | 支持的修饰符 |
|-------------|-------------|---------|-------------|
| THEN | `THEN(...)` | `THEN(a, b, c)` | `.id()`, `.tag()` |
| WHEN | `WHEN(...)` | `WHEN(a, b, c)` | `.maxWaitSeconds()`, `.ignoreError()`, `.must()`, `.any()` |
| IF | `IF(...).ELSE(...)` | `IF(x, a, b)` | `.ELIF()` |
| SWITCH | `SWITCH(...).to(...)` | `SWITCH(x).to(a, b).id('A', 'B')` | `.DEFAULT()` |
| FOR | `FOR(...).DO(...)` | `FOR(5).DO(a)` | `.BREAK()`, `.parallel()` |
| WHILE | `WHILE(...).DO(...)` | `WHILE(x).DO(a)` | `.BREAK()`, `.parallel()` |
| ITERATOR | `ITERATOR(...).DO(...)` | `ITERATOR(x).DO(a)` | `.BREAK()`, `.parallel()` |
| CATCH | `CATCH(...).DO(...)` | `CATCH(a).DO(b)` | - |
| AND | `AND(...)` | `AND(x, y)` | - |
| OR | `OR(...)` | `OR(x, y)` | - |
| NOT | `NOT(...)` | `NOT(x)` | - |

## 六、EL 表达式生成器

### 6.1 ELGenerator 实现

```typescript
// utils/elGenerator.ts

import type { CmpProperty } from '../types/flow';

/**
 * EL 表达式生成器
 * 将 CmpProperty 树结构转换为 LiteFlow EL 表达式
 *
 * 支持格式:
 * - 单行模式: THEN(a, b, c)
 * - 多行模式: 带缩进的格式化输出
 */
export class ELGenerator {
  /**
   * 生成 EL 表达式
   * @param root 根节点
   * @param formatted 是否格式化 (多行)
   */
  static toEL(root: CmpProperty, formatted = false): string {
    const prefix = formatted ? '' : undefined;
    return this.generate(root, prefix);
  }

  private static generate(node: CmpProperty, prefix?: string): string {
    if (!node) return '';

    const type = node.type?.toUpperCase();

    switch (type) {
      case 'THEN':
      case 'SER':
        return this.generateThen(node, prefix);
      case 'WHEN':
      case 'PAR':
        return this.generateWhen(node, prefix);
      case 'IF':
        return this.generateIf(node, prefix);
      case 'SWITCH':
        return this.generateSwitch(node, prefix);
      case 'FOR':
        return this.generateFor(node, prefix);
      case 'WHILE':
        return this.generateWhile(node, prefix);
      case 'ITERATOR':
        return this.generateIterator(node, prefix);
      case 'CATCH':
        return this.generateCatch(node, prefix);
      case 'AND':
        return this.generateAnd(node, prefix);
      case 'OR':
        return this.generateOr(node, prefix);
      case 'NOT':
        return this.generateNot(node, prefix);
      default:
        // 叶子节点 (组件引用)
        return this.getNodeId(node);
    }
  }

  private static getNodeId(node: CmpProperty): string {
    return node.componentRef || node.id || '';
  }

  private static generateThen(node: CmpProperty, prefix?: string): string {
    const children = node.children?.map(c => this.generate(c, prefix ? `${prefix}  ` : undefined)) || [];
    const modifiers = this.generateModifiers(node.properties);

    if (prefix !== undefined) {
      return `${prefix}THEN(\n${children.map(c => `${prefix}  ${c}`).join(',\n')}\n${prefix})${modifiers}`;
    }
    return `THEN(${children.join(', ')})${modifiers}`;
  }

  private static generateWhen(node: CmpProperty, prefix?: string): string {
    const children = node.children?.map(c => this.generate(c, prefix ? `${prefix}  ` : undefined)) || [];
    let modifiers = '';

    if (node.properties) {
      const props = node.properties;
      if (props.maxWaitSeconds) modifiers += `.maxWaitSeconds(${props.maxWaitSeconds})`;
      if (props.ignoreError) modifiers += `.ignoreError(true)`;
      if (props.must) modifiers += `.must()`;
    }
    modifiers += this.generateModifiers(node.properties, ['maxWaitSeconds', 'ignoreError', 'must']);

    if (prefix !== undefined) {
      return `${prefix}WHEN(\n${children.map(c => `${prefix}  ${c}`).join(',\n')}\n${prefix})${modifiers}`;
    }
    return `WHEN(${children.join(', ')})${modifiers}`;
  }

  private static generateIf(node: CmpProperty, prefix?: string): string {
    if (!node.condition) throw new Error('IF 节点必须有条件');
    if (!node.children?.length) throw new Error('IF 节点必须有分支');

    const condition = this.generate(node.condition);
    const trueBranch = this.generate(node.children[0]);
    const falseBranch = node.children[1] ? this.generate(node.children[1]) : null;
    const modifiers = this.generateModifiers(node.properties);

    if (falseBranch) {
      return `IF(${condition}, ${trueBranch}, ${falseBranch})${modifiers}`;
    }
    return `IF(${condition}, ${trueBranch})${modifiers}`;
  }

  private static generateSwitch(node: CmpProperty, prefix?: string): string {
    if (!node.condition) throw new Error('SWITCH 节点必须有条件');
    if (!node.children?.length) throw new Error('SWITCH 节点必须有分支');

    const condition = this.generate(node.condition);
    const branches: string[] = [];
    const branchIds: string[] = [];

    node.children.forEach(child => {
      branches.push(this.generate(child));
      const branchId = child.properties?.branch || this.getNodeId(child);
      branchIds.push(`'${branchId}'`);
    });

    let result = `SWITCH(${condition}).to(${branches.join(', ')})`;
    if (branchIds.length > 0) {
      result += `.id(${branchIds.join(', ')})`;
    }

    return result + this.generateModifiers(node.properties, ['branch']);
  }

  private static generateFor(node: CmpProperty, prefix?: string): string {
    if (!node.children?.length) throw new Error('FOR 节点必须有子节点');
    const loopCount = node.properties?.loopCount;
    if (!loopCount) throw new Error('FOR 节点必须指定循环次数');

    const body = this.generate(node.children[0]);
    let result = `FOR(${loopCount}).DO(${body})`;

    if (node.properties?.breakCondition) {
      const breakCond = this.generate(node.properties.breakCondition);
      result += `.BREAK(${breakCond})`;
    }

    return result + this.generateModifiers(node.properties, ['loopCount', 'breakCondition']);
  }

  private static generateWhile(node: CmpProperty, prefix?: string): string {
    if (!node.condition) throw new Error('WHILE 节点必须有条件');
    if (!node.children?.length) throw new Error('WHILE 节点必须有子节点');

    const condition = this.generate(node.condition);
    const body = this.generate(node.children[0]);
    let result = `WHILE(${condition}).DO(${body})`;

    if (node.properties?.breakCondition) {
      const breakCond = this.generate(node.properties.breakCondition);
      result += `.BREAK(${breakCond})`;
    }

    return result + this.generateModifiers(node.properties, ['breakCondition']);
  }

  private static generateIterator(node: CmpProperty, prefix?: string): string {
    if (!node.condition) throw new Error('ITERATOR 节点必须有迭代器');
    if (!node.children?.length) throw new Error('ITERATOR 节点必须有子节点');

    const iterator = this.generate(node.condition);
    const body = this.generate(node.children[0]);
    let result = `ITERATOR(${iterator}).DO(${body})`;

    if (node.properties?.breakCondition) {
      const breakCond = this.generate(node.properties.breakCondition);
      result += `.BREAK(${breakCond})`;
    }

    return result;
  }

  private static generateCatch(node: CmpProperty, prefix?: string): string {
    if (!node.children?.length) throw new Error('CATCH 节点必须有子节点');

    const tryBody = this.generate(node.children[0]);
    let result = `CATCH(${tryBody})`;

    if (node.children.length > 1) {
      const catchBody = this.generate(node.children[1]);
      result += `.DO(${catchBody})`;
    }

    return result + this.generateModifiers(node.properties);
  }

  private static generateAnd(node: CmpProperty, prefix?: string): string {
    if (!node.children || node.children.length < 2) {
      throw new Error('AND 节点至少需要两个子节点');
    }
    const children = node.children.map(c => this.generate(c));
    return `AND(${children.join(', ')})`;
  }

  private static generateOr(node: CmpProperty, prefix?: string): string {
    if (!node.children || node.children.length < 2) {
      throw new Error('OR 节点至少需要两个子节点');
    }
    const children = node.children.map(c => this.generate(c));
    return `OR(${children.join(', ')})`;
  }

  private static generateNot(node: CmpProperty, prefix?: string): string {
    if (!node.children?.length) throw new Error('NOT 节点必须有子节点');
    const child = this.generate(node.children[0]);
    return `NOT(${child})`;
  }

  /**
   * 生成通用修饰符
   */
  private static generateModifiers(props?: CmpProperty['properties'], exclude: string[] = []): string {
    if (!props) return '';

    const parts: string[] = [];

    if (!exclude.includes('id') && props.id) {
      parts.push(`.id("${props.id}")`);
    }
    if (!exclude.includes('tag') && props.tag) {
      parts.push(`.tag("${props.tag}")`);
    }
    if (!exclude.includes('data') && props.data) {
      parts.push(`.data("${props.data}")`);
    }

    return parts.join('');
  }
}

// stores/flowStore.ts

import { create } from 'zustand';

interface FlowActions {

export const useFlowStore = create<FlowState & FlowActions>((set, get) => ({

  flowName: '未命名流程',
  flowDescription: '',
  rootNode: null,
  selectedNode: null,
  graph: null,
  elExpression: '',
  dirty: false,
  loading: false,
  error: null,

  // ===== 流程操作 =====
  newFlow: () => {
    const rootNode = ELBuilder.createChain();
    set({
      flowId: null,
      flowName: '未命名流程',
      flowDescription: '',
      rootNode,
      selectedNode: null,
      elExpression: '',
      dirty: false,
    });

  loadFlow: async (flowId: string) => {
    set({ loading: true, error: null });
    try {
      const { data } = await flowApi.get(flowId);
      const rootNode = ELBuilder.build(data.root);
      const elExpression = ELGenerator.toEL(data.root);

      set({
        flowId: data.flowId,
        flowName: data.flowName,
        flowDescription: data.description || '',
        rootNode,
        elExpression,
        dirty: false,
        loading: false,
      });
    } catch (error: any) {
      set({ error: error.message, loading: false });
      throw error;
    }
  },

  saveFlow: async () => {
    const { flowId, flowName, flowDescription, rootNode } = get();
    if (!rootNode) return;

    set({ loading: true, error: null });
    try {
      const flowDesign: FlowDesign = {
        flowId: flowId || `flow_${Date.now()}`,
        flowName,
        description: flowDescription,
        root: rootNode.toJSON(),
      };

      if (flowId) {
        await flowApi.update(flowId, flowDesign);
      } else {
        const { data } = await flowApi.create(flowDesign);
        set({ flowId: data.flowId });
      }

      set({ dirty: false, loading: false });
    } catch (error: any) {
      set({ error: error.message, loading: false });
      throw error;
    }
  },

  clearFlow: () => {
    set({
      flowId: null,
      flowName: '未命名流程',
      flowDescription: '',
      rootNode: null,
      selectedNode: null,
      elExpression: '',
      dirty: false,
    });
  },

  // ===== 节点操作 =====
  setRootNode: (node) => {
    set({ rootNode: node, dirty: true });
    get().syncToGraph();
    get().generateEL();
  },

  selectNode: (node) => {
    set({ selectedNode: node });
  },

  addNode: (parent, node, index) => {
    parent.appendChild(node, index);
    set({ dirty: true });
    get().syncToGraph();
    get().generateEL();
  },

  removeNode: (node) => {
    if (node.parent) {
      node.parent.removeChild(node);
      set({ dirty: true, selectedNode: null });
      get().syncToGraph();
      get().generateEL();
    }
  },

  updateNode: (node, updates) => {
    Object.assign(node, updates);
    set({ dirty: true });
    get().syncToGraph();
    get().generateEL();
  },

  replaceNode: (oldNode, newNode) => {
    oldNode.replace(newNode);
    set({ dirty: true, selectedNode: newNode });
    get().syncToGraph();
    get().generateEL();
  },

  // ===== Graph 操作 =====
  setGraph: (graph) => {
    set({ graph });
  },

  syncToGraph: () => {
    const { graph, rootNode } = get();
    if (!graph || !rootNode) return;

    // 清空画布
    graph.clearCells();

    // 从 ELNode 生成 X6 cells
    const cells = rootNode.toCells();
    graph.addCell(cells);

    // 自动布局
    get().refreshLayout();
  },

  refreshLayout: () => {
    const { graph } = get();
    if (!graph) return;
    // 触发 Dagre 布局
    // 具体实现参考 liteflow-editor-client
  },

  // ===== EL 操作 =====
  generateEL: () => {
    const { rootNode } = get();
    if (!rootNode) return '';

    const el = rootNode.toEL();
    set({ elExpression: el });
    return el;
  },

  previewEL: async () => {
    const { rootNode } = get();
    if (!rootNode) return '';

    try {
      const { data } = await flowApi.previewEL(rootNode.toJSON());
      set({ elExpression: data.el });
      return data.el;
    } catch (error) {
      // 使用本地生成
      return get().generateEL();
    }
  },

  // ===== 验证与部署 =====
  validateFlow: async () => {
    const { rootNode, flowId, flowName } = get();
    if (!rootNode) {
      return { valid: false, errors: ['流程为空'] };
    }

    try {
      const flowDesign: FlowDesign = {
        flowId: flowId || 'temp',
        flowName,
        root: rootNode.toJSON(),
      };
      const { data } = await flowApi.validateDesign(flowDesign);
      return { valid: data.valid, errors: data.errors || [] };
    } catch (error: any) {
      return { valid: false, errors: [error.message] };
    }
  },

  deployFlow: async () => {
    const { flowId } = get();
    if (!flowId) {
      throw new Error('请先保存流程');
    }
    await flowApi.deploy(flowId);
  },
}));
```

## 十、关键变更说明

### 10.1 相比 V1.0 的主要改进

| 方面 | V1.0 问题 | V2.0 改进 |
|------|----------|----------|
| **节点类型** | 自定义枚举，与 liteflow-editor-client 不一致 | 对齐 `NodeTypeEnum` 和 `ConditionTypeEnum` |
| **数据模型** | 前端 ELNode 与后端 CmpProperty 不完全匹配 | 严格对齐后端模型，确保 JSON 双向转换无误 |
| **API 路径** | 部分接口路径猜测 | 根据后端 Controller 实际路径准确对接 |
| **EL 生成** | 部分语法不完整 | 支持所有 LiteFlow EL 操作符和修饰符 |
| **节点分类** | 分组逻辑简单 | 参考 liteflow-editor-client 分组设计，支持动态加载业务组件 |
| **技术方案** | @xyflow/react (变更为 X6) | 确认使用 @antv/x6，与 liteflow-editor-client 保持一致 |

### 10.2 需要后端配合的事项

1. **确认 API 响应格式**: 统一返回 `{ code, data, message }` 格式
2. **组件列表增加分类筛选**: `GET /api/component/list?componentType=BOOLEAN`
3. **流程预览 EL 接口**: 确认 `POST /api/flow/preview-el` 只需要 `root` 参数
